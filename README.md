## 📖 About Sinhala Studio Engine

**Sinhala Studio Video Engine (`SinhalaStudioEngine.exe`)** is a lightweight, zero-configuration local companion service for Windows that powers high-fidelity media downloads and cloud bridge workflows for the **Sinhala Studio Chrome Extension**.

It runs securely and silently in the background on your PC (`http://127.0.0.1:58855`), enabling instant 1-click 1080p video downloading with universal AAC audio and direct Google Drive cloud saving.

---

## 🚀 Key Features

- **🎬 1080p Video Downloads to PC:** Download full high-definition videos with 100% crystal-clear synchronized audio from:
  - ▶️ **YouTube** (Videos, Shorts)
  - 🎵 **TikTok** (Watermark-free videos)
  - 📘 **Facebook** (Reels & Public Videos)
  - 📸 **Instagram** (Reels, Posts & Audio)
  - 🎶 **Suno AI** (High-quality M4A song downloads)
  - 🐦 **X / Twitter** (Media videos)
- **☁️ Personal Google Drive Sync:** Direct, high-speed cloud upload straight to your private Google Drive folder with 0 MB permanent disk usage on PC.
- **⚡ 0 MB Personal Data Cloud Mode:** 1-Click Google Colab Cloud integration for massive video archives without consuming personal mobile data.
- **🔒 100% Safe & Local:** Operates exclusively on local loopback (`127.0.0.1:58855`). No telemetry, no external data harvesting, and no ads.

## 📥 Quick Setup Guide (පියවර 3 කින් ආරම්භ කරන්න)

### Step 1: Download the Engine
Click the link below to download the latest executable binary:

👉 **[Download SinhalaStudioEngine.exe (Latest Release)](https://github.com/DMadushanka/Sinhala_studio/releases/latest/download/SinhalaStudioEngine.exe)**

*(Or browse all versions on the [Releases Page](https://github.com/DMadushanka/Sinhala_studio/releases))*

### Step 2: Run on Your PC
- Once downloaded, double-click **`SinhalaStudioEngine.exe`**.
- A small status window will confirm:  
  `🟢 Sinhala Studio Video Engine started successfully on port 58855`.
- You can minimize it or keep it running in the background.

### Step 3: Use with Sinhala Studio Extension
- Open any supported video page (YouTube, TikTok, Instagram, Suno AI, Facebook).
- Hover over the video and click the **Save to Drive** (☁️) or **Download to PC** (⬇️) button!
